# 🍽️ Unified Restaurant POS System (Python Tkinter)

A **real-life Restaurant Point of Sale (POS) System** built using **Python & Tkinter**, featuring order management, billing, stock control, receipt storage, and sales reports.

---

## ✨ Key Features

### 🧾 Order Management
- Add items to cart
- Increment / decrement quantity
- Remove items from cart
- Real-time total calculation

---

### 📦 Inventory Management
- Live stock tracking
- Low-stock alert
- Auto-disable out-of-stock items

---

### 💳 Billing System
- Automatic bill calculation
- Error-free checkout
- Receipt generation

---

### 🧾 Receipt Management
- Receipts stored in **`receipts/`** folder
- Timestamp-based file names
- Printable format

---

### 📊 Sales Reports
- Daily sales report
- Weekly sales report
- Export reports to CSV
- Stored inside **`reports/`** folder

---

### 🛡️ Validation & Error Handling
- Quantity validation
- Stock availability check
- Safe file/database writes

---

## 🛠️ Technologies Used
- Python 3
- Tkinter
- JSON
- CSV
- File Handling
