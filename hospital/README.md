# 🏥 Hospital Appointment & Queue Management System (Python Tkinter)

A **hospital OPD simulation system** developed using **Python & Tkinter**, designed to manage patient registration, doctor queues, appointment flow, and status tracking.

---

## ✨ Key Features

### 🧑‍⚕️ Patient Registration
- Register patients with validation
- Auto-generated patient IDs
- Error-safe input handling

---

### 🏥 Doctor & Ward Management
- Multiple doctors
- Different hospital wards
- Doctor-wise queues

---

### ⏳ Queue Management
- Live OPD queue display
- Patient call system
- Queue advancement logic

---

### 📊 Status Tracking
- Waiting
- In Consultation
- Completed

---

### 🛡️ Validations & Safety
- Duplicate patient prevention
- Required field checks
- Safe JSON database writes

---

## 🛠️ Technologies Used
- Python 3
- Tkinter
- JSON
- File Handling
